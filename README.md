# green-apple

## Apps

- `frontend` - Angular client
- `backend` - Node.js + PostgreSQL API

## Quick Start

### Frontend

- `cd frontend`
- `npm install`
- `npm start`

### Backend

- `cd backend`
- `npm install`
- copy `.env.example` to `.env`
- ensure PostgreSQL is running and database exists
- `npm run db:init`
- `npm run dev`
